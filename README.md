# Advanced Calculator

Мобильное приложение-калькулятор на Flutter для лабораторной работы №1 «Продвинутый калькулятор».

## Назначение

Приложение позволяет вводить произвольные арифметические выражения и вычислять их с учётом приоритета операций и скобок. Логика вычислений отделена от пользовательского интерфейса.

## Основные возможности

- Ввод и вычисление произвольных выражений
- Операции `+`, `−`, `×`, `÷`
- Вещественные числа, скобки и математический приоритет
- Кнопки `=`, `C`, `⌫`, `%`, `±`
- История последних 10 успешных вычислений
- Память калькулятора: `M+`, `M−`, `MR`, `MC`
- Сохранение состояния через `shared_preferences` (выражение, результат, ошибка, память, история)

## Используемые технологии

- Flutter / Dart (null-safety)
- Material 3
- `shared_preferences` для постоянного хранения состояния

Готовые пакеты-вычислители не используются: парсер реализован самостоятельно.

## Архитектура

```text
lib/
├── main.dart
├── models/
│   ├── calculation_history_item.dart
│   ├── calculator_error.dart
│   └── calculator_persisted_state.dart
├── services/
│   ├── expression_evaluator.dart
│   └── storage_service.dart
├── controllers/
│   └── calculator_controller.dart
├── screens/
│   └── calculator_screen.dart
└── widgets/
    ├── calculator_button.dart
    ├── calculator_display.dart
    ├── history_sheet.dart
    └── memory_buttons.dart
```

- `ExpressionEvaluator` — токенизатор и рекурсивный спуск (`expression` → `term` → `unary` → `postfix` → `primary`)
- `CalculatorController` — состояние, ввод, история, память и сохранение
- `StorageService` — загрузка и сохранение состояния
- UI только отображает состояние и вызывает методы контроллера

Ориентация экрана не блокируется: для portrait и landscape используются разные компоновки.

## Поддерживаемые операции

| Символ | Операция |
|--------|----------|
| `+` | сложение |
| `−` | вычитание |
| `×` | умножение |
| `÷` | деление |
| `( )` | скобки |
| `%` | текущий операнд делится на 100 (`50% = 0.5`) |
| `±` | смена знака текущего числа |

Примеры:

- `12 + 5 × 3 = 27`
- `(12 + 5) × 3 = 51`

## Обработка ошибок

Вычислитель не пробрасывает необработанные исключения наружу. Пользователь видит понятные сообщения, приложение продолжает работать:

- `Деление на ноль`
- `Неправильные скобки`
- `Два оператора подряд`
- `Некорректное число`
- `Пустое выражение`
- `Выражение заканчивается оператором`
- `Некорректное выражение`

После ошибки можно продолжить редактирование выражения.
